### 风格四：动态杂志风 (Dynamic Editorial)

```
模式：沉浸式编辑排版界面 (Editorial Immersive Interface)
CTA：胶囊型线性按钮 (Pill-shaped Outline Button)，悬停反色
区块：
  1. 顶部全屏视觉大片 Banner (Cinematic Full-Bleed Hero Image)
  2. 居中留白文字导航 Tab (Centered Negative Space Typography Tabs)
  3. 极细时间线 & 不对称网格大图卡片 (Hairline Timeline & Asymmetrical Image Grid)
  4. 带语义图标的浅色胶囊提示框 (Pill-shaped Hint Box with Icons)
  5. 卷尾语/编者按式提示区 (Editor's Note / Colophon Hint Area)

风格：Kinfolk / CEREAL 极简美学 & 留白艺术
关键词：大面积留白，不对称网格，无边框大图，衬线体，极细分割线，
        低饱和度，高级感，呼吸感，胶囊元素点缀，拍立得相纸破局排版

配色：
  主色 (强调/标题)：#111111
  辅助色 (装饰)：   #A69F95 (莫兰迪灰褐/燕麦色)
  背景 (空间)：     #FFFFFF 或 #FAF9F8
  文本 (正文)：     #4A4A4A
  环境色：          由摄影原图决定，图片施加 grayscale 降饱和度

排版：Playfair Display (标题) & Inter / Helvetica Neue (正文)

关键特效：
  1. 慢镜头缩放：图片 Hover 缩放 (scale: 1.03, 1.5s ease-out)
  2. 阶梯式动画：Tab 切换时瀑布阶梯式滑入淡现 (Staggered Fade-in up)
  3. 多层级视差：Banner 滚动视差 + 时间节点/胶囊框/图片交错浮动视差
     (时间数字和副标题放同一视差容器，防止滚动时重叠)

特殊元素：
  - Tab 导航完全居中，仅保留 DAY 1 / 2 / 3
  - 拍立得相纸 (Polaroid) 样式：细微阴影 + 旋转角 (-3deg) 手账随性感
  - 所有 Tip 替换为浅底色圆角胶囊 + SVG 图标
  - 全局视差滑动系统
```
